Privacy Policy

Last updated: November 11, 2026

The Small Ink Stories upload tool is a private script that the owner of the Small Ink Stories YouTube channel runs on their own computer to upload the channel's own videos. It is not offered to the public, and no one else signs in to it.

What the tool accesses

With the channel owner's permission, given through Google sign-in, the tool uses the YouTube Data API to: read the name and ID of the signed-in channel, upload videos, set their titles, descriptions, thumbnails and publishing schedule, and add them to playlists.

What is stored and shared

The sign-in token is stored only on the owner's computer. The tool does not collect, sell or share any personal data, and it sends nothing to any server other than Google's.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs follows the Google API Services User Data Policy.
